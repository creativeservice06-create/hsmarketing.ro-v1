HARD SERVICE V8 — PUBLICARE GITHUB/VERCEL

1. Deschide arhiva ZIP și copiază CONȚINUTUL EI în rădăcina repository-ului.
   În GitHub trebuie să fie vizibile direct package.json, app/, components/, lib/, public/.
2. În Vercel: Root Directory = ./ (dacă package.json este în rădăcină).
3. Framework Preset: Next.js. Build command: npm run build.
4. Configurează variabilele SMTP pentru formular, conform .env.example.
5. Fă întâi Deploy Preview; verifică formularul, telefonul, logo-urile externe, paginile SEO și mobilul.
6. Badge-urile Meta/Google au fost furnizate de utilizator. Publică-le numai dacă sunt conforme cu statutul companiei și regulile titularilor. Google poate impune fragmentul HTML oficial pentru badge-ul de pe website.

Logo-urile portofoliului sunt faviconurile publice ale domeniilor și se încarcă extern. Pot diferi de siglele lor principale. Dacă ai identitățile complete (SVG/PNG), înlocuiește-le cu acelea, după verificarea drepturilor.
